PROVEN, IN THE ORDER THE EVIDENCE WAS ESTABLISHED.

1. SNAPSHOTTING AT EVAL TIME IS REQUIRED, NOT TIDY. ggml runs the head norm and
   RoPE IN PLACE. Pointer equality proves an edge, but a backend pointer retained
   past the callback reads whatever an in-place successor wrote. Every tensor is
   copied into probe-owned storage at its own eval callback, with the pointer kept
   separately as provenance. The pointer is graph evidence; the copy is the reading.

2. CORRELATION IS BY GRAPH IDENTITY. A normed/roped pair is accepted only when
   roped.src0 == normed.data. Name matching cannot work: over 1266 events the
   inventory is Qcur x180, Kcur x144, Qcur_normed x36, Kcur_normed x36. These names
   are per-layer and never unique. An earlier first-match-by-name run paired one
   layer with another and produced a post-norm vector spanning +-12.2 beside a
   post-RoPE vector spanning +-0.27, impossible for one vector.

3. PRE-NORM IS FOUND BY TRAVERSING src[0] BACKWARDS, NOT BY ADDRESS. ggml reuses
   storage, so one address carries attn_norm, then the projection, then the head
   norm. Searching by address conflated them and produced a WRONG K tensor, caught
   only by step 4. The chain resolved here, on both sides:
       Qcur_normed(MUL) -> src0 -> RMS_NORM -> src0 -> MUL_MAT
       Kcur_normed(MUL) -> src0 -> RMS_NORM -> src0 -> MUL_MAT
   The producer is snapshotted in its OWN eval callback and bound by graph node
   identity and eval sequence, never by name or address. (The intermediate MUL is
   the scale-by-1/sqrt(head_dim) that build_attn applies to Q and K.)

4. RMS RECONSTRUCTION CONFIRMS THE TRAVERSAL ARITHMETICALLY. RMSNorm is
   out = in * weight * inv_rms with inv_rms from in. Relative to post-norm scale:
     Q  max abs 6.89e-07 over scale 12.2024  = 5.65e-08
     K  max abs 7.96e-06 over scale 169.416  = 4.70e-08
   Traversal alone is a structural claim; this makes it a measured one.

5. THE NORM IS APPLIED BEFORE RoPE, PROVED FROM SOURCE. qwen3.cpp line 88 norm vs
   91 rope, and 97 vs 100 for K. RMS not LayerNorm: LLM_NORM_RMS maps to
   ggml_rms_norm at llama-graph.cpp:1600, and qwen3.cpp never creates the bias
   tensors, though llama-model.h declares the slots.

6. RoPE IS NEOX / ROTATE-HALF, DETERMINED FROM THE NUMBERS NOT THE NAME.
     worst adjacent pair (k, k+1)  rel = 2.65 for Q, 2.55 for K   NOT preserved
     worst NEOX pair    (k, k+64) rel = 7.72e-08 Q, 8.69e-08 K    preserved
   Element k is rotated with k + hd/2. An adjacent-pair gate would have FAILED a
   correct model, which is the same error class as a gate that passes a wrong one.

7. DIMENSIONS AND COUNTS. Q is 32 x 128 = 4096, K is 8 x 128 = 1024. Confirmed
   independently: key_length u32 128, head_count 32, head_count_kv 8, the
   { n_embd_head_k } tensor shape at qwen3.cpp:39-40, and ne [128,1] F32 captures.
   The norm reduces 128 head elements, not n_embd 4096, so it is 32x narrower than
   any BitNet norm, and each of the 8 KV heads needs its own K norm.
